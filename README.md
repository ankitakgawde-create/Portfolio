# Ankita Gawde — About page test

A portable HTML, CSS, and JavaScript implementation of Figma frame 1:683 in the portfolio file. No Webflow runtime or build tools are required.

Open index.html to view, or serve this folder with a static server. For GitHub Pages, upload the contents of this folder to the publishing branch and enable Pages in repository settings.

Included behavior: responsive mobile menu, working email and LinkedIn links, résumé link, button hover states, and a looping photo gallery with pause control and reduced-motion support. These are implemented in code; the Figma import does not transfer Webflow interaction logic.

Scope: only the About page is implemented. Work and the brand link currently open the existing live portfolio. The mobile layout is adapted from the supplied desktop design and needs your review. No domain or production hosting changes have been made.

Design content is retained, including the fourth process step titled “Strategise.” The imported malformed LinkedIn URL is corrected. The empty imported spacer is preserved without adding an image.
