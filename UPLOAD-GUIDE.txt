# Ankita Gawde portfolio — GitHub upload package

This folder contains 7 pages: Home, About, Activity Tracker Redesign, AI Cell Detection Tool, Device Monitoring Platform, Recipe Management, and LinkedIn Accessibility Fixes.

The homepage and About page use the existing rebuilt layouts. The five project pages are static copies of your public Webflow pages, with their images, fonts, styles, scripts, PDF and video saved locally. Small phone-layout refinements are in project-responsive.css. Webflow-generated styles and browser scripts are retained for these project pages. No Webflow hosting is needed to serve this package. This is a static migration of the published pages, not an official Webflow project export or a two-way Figma connection.

## Upload to your existing GitHub repository

1. Extract portfolio-all-pages.zip on your computer. Open the portfolio folder inside it.
2. Open your Portfolio repository on GitHub. Click Code to view its top-level file list.
3. Click Add file > Upload files.
4. From inside the extracted portfolio folder, select all HTML, CSS and JS files, plus README.md and UPLOAD-GUIDE.txt. Upload those files directly. Do not upload the ZIP or the outer portfolio folder.
5. Enter a message such as "Add all portfolio pages". Click Commit changes. Replacing files with the same names updates your existing pages.
6. Open the assets folder in your GitHub repository. Click Add file > Upload files. Upload the CONTENTS of the extracted assets folder into this existing GitHub assets folder. Use batches of about 50 files, committing each batch. Upload every batch, including images, fonts, CSS, JS, PDF and video files.
7. If assets does not exist yet, go to the repository root, choose Add file > Create new file, type assets/.gitkeep as the filename, then Commit changes. This creates the folder; open it and follow step 6.
8. Wait for the Pages deployment in Actions to finish successfully. Committing files automatically starts a new deployment with your existing Pages settings. No manual rerun is normally needed.
9. Open Settings > Pages and use Visit site to open the correct address. Refresh the page after deployment. If the old version remains, use Cmd + Shift + R.
10. Check Home, About and all five project links. Try a phone-sized window too. We can review hover effects, scrolling, videos and other interactions next.
